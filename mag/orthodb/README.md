# OrthoDB Downloader (заглушка)

Заглушка для будущей утилиты скачивания данных OrthoDB.

## Назначение

OrthoDB — база данных ортологов (https://www.orthodb.org/).
Будет использоваться для построения колонки паралогов/ортологов
в дополнение к данным Ensembl Compara.

## Статус

⚠️ Заглушка. Будет реализована в дальнейшем.

## Планируемая функциональность

- Скачивание ortholog-таблиц по видам
- Скачивание паралогов
- Интеграция с ensembl/ для объединения данных

## Использование

```bash
python main.py --help
```
